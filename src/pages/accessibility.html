Accessibility

This site is built to be usable by everyone, including people using assistive technology.

Our approach

We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA. In practice that means the site is built with the following in place:

  • Semantic HTML with a single, logical heading order on every page
  • A skip link so keyboard users can bypass the navigation
  • Visible focus indicators on every interactive element
  • Full keyboard operability, including the mobile menu and the FAQ
  • Text and interface colors that meet AA contrast ratios
  • Form fields with real labels, clear required-field marking, and helpful hints
  • Text that reflows without loss of content at 200 percent zoom
  • Respect for the operating system reduced-motion preference
  • No content that flashes or auto-plays

Known limitations

We link to the FMCSA carrier lookup, which is a government site outside our control. We cannot guarantee the accessibility of pages we do not operate.
